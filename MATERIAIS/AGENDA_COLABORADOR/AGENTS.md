# Instruções para agentes

Antes de iniciar qualquer tarefa nesta pasta, leia integralmente o arquivo `CLAUDE.md` localizado nesta mesma pasta e siga rigorosamente todas as instruções nele contidas.

As instruções do `CLAUDE.md` aplicam-se a todo o trabalho realizado neste projeto e devem ser consultadas novamente quando necessário para cumprir seu conteúdo por completo.

Ao trabalhar no projeto `AUTOMATIZACAO-WHATSAPP`, leia também integralmente o arquivo `AUTOMATIZACAO-WHATSAPP/CLAUDE.md`. As instruções e informações específicas desse projeto — como objetivo, arquitetura, requisitos e orientações — estão registradas nesse arquivo e devem ser seguidas junto com as instruções gerais acima.
