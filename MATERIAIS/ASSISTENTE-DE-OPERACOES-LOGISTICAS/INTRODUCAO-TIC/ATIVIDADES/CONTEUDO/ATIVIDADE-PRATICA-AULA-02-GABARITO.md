**Regra geral de correção de cada tópico:** nota cheia = atende a todos os critérios com as
palavras do aluno; metade = atende parcialmente (conceito certo, mas incompleto ou sem aplicar ao

### ITEM 01-a
**Resposta esperada:** Hardware: processador Intel Core i5, memória RAM de 8 GB, SSD de 480 GB, placa-mãe. Software: Windows 11, sistema WMS, planilha eletrônica, leitor de PDF.
**Critérios:** Nota cheia: os oito itens certos. Metade: seis ou sete certos. Zero: cinco ou menos.

### ITEM 01-b
**Resposta esperada:** Hardware é a parte física (o "corpo"): peças, cabos e circuitos que se pode tocar. Software é a parte lógica (a "mente"): programas e instruções que dizem à máquina o que fazer. O hardware sem software fica parado, e o software precisa do hardware para ser executado.
**Critérios:** Nota cheia: diferença correta + dependência entre os dois. Metade: só a diferença. Zero: definições trocadas.

### ITEM 02-a
**Resposta esperada:** CPU: o "cérebro", busca e executa as instruções e faz os cálculos (ULA, UC, registradores). RAM: guarda temporariamente os dados dos programas em uso, com acesso rápido. Volátil: perde tudo quando o computador é desligado.
**Critérios:** Nota cheia: função da CPU + função da RAM + volatilidade. Metade: dois desses. Zero: um ou nenhum.

### ITEM 02-b
**Resposta esperada:** Placa-mãe: interliga todos os componentes por barramentos (soquete da CPU, slots, chipset). SSD: armazenamento permanente dos arquivos e do sistema, com memória Flash, rápido e sem peças móveis.
**Critérios:** Nota cheia: as duas funções corretas. Metade: uma correta. Zero: nenhuma.

### ITEM 03-a
**Resposta esperada:** SSD: muito mais rápido (até 10 vezes), resistente a impactos (sem peças móveis), mais caro por TB. HDD: mais lento, vulnerável a impactos (pratos e agulha), mais barato por TB.
**Critérios:** Nota cheia: compara os três aspectos. Metade: dois aspectos. Zero: um ou comparação errada.

### ITEM 03-b
**Resposta esperada:** Com pouca RAM, o sistema usa memória virtual no disco (que é lento, ainda mais num HDD) para rodar o WMS e a planilha juntos, e o computador trava. Recomendação: trocar o HDD por SSD (melhora a inicialização e todo o acesso a disco) ou aumentar a RAM para 8 GB, desde que justificado pelos sintomas (inicialização lenta → SSD; travar com vários programas → RAM).
**Critérios:** Nota cheia: explica a memória virtual/falta de RAM + recomenda uma troca com justificativa coerente. Metade: só um dos dois. Zero: sem relação.
