| **Dica Visual** | Badge "3 min para pensar + compartilhar com colega" | 14pt, Fundo amarelo #fff9e6 |

**Ações:**
1. Adicionar imagem grande (estoque: person-bored-presentation.jpg)
2. Posicionar texto à direita com contraste forte
3. Destacar palavra-chave "PIOR" em vermelho #e74c3c
4. Adicionar timer visual (ícone relogio)

### SLIDE 9: "Pilares do Design Visual — Antes/Depois"

| ANTES | DEPOIS |
|-------|--------|

**Repetir para:**
- Tipografia (Múltiplas fontes → 2 fontes)
- Alinhamento (Caótico → Grid perfeito)
- Espaço Negativo (Poluído → Respirado)

**Ações:**
1. Criar 4 pares antes/depois
2. Seta de transformação grande entre cada par
3. Imagens reais mostrando a mudança
4. Métricas de melhora (ex: "+45% legibilidade")
5. Checkmark verde ✅ no "depois"

