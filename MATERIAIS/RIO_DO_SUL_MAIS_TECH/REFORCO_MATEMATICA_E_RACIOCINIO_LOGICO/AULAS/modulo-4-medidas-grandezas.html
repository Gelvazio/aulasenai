📚 2. Área e Perímetro

Perímetro: É a soma de todos os lados de uma figura

Área: É o espaço dentro de uma figura plana

Quadrado

Perímetro = lado × 4 = L × 4
Área = lado × lado = L²

Se lado = 5cm:
Perímetro = 5 × 4 = 20cm
Área = 5 × 5 = 25cm²

Retângulo

Perímetro = 2 × (comprimento + largura) = 2(C + L)
Área = comprimento × largura = C × L

Se C = 8m e L = 5m:
Perímetro = 2 × (8 + 5) = 26m
Área = 8 × 5 = 40m²

Triângulo

Perímetro = lado1 + lado2 + lado3
Área = (base × altura) ÷ 2

Se base = 10cm e altura = 6cm:
Área = (10 × 6) ÷ 2 = 30cm²

Círculo

Perímetro (Circunferência) = 2 × π × raio = 2πr
Área = π × raio² = πr²

Se raio = 5m (π ≈ 3,14):
Perímetro = 2 × 3,14 × 5 = 31,4m
Área = 3,14 × 5² = 78,5m²

📚 3. Volume

Volume é o espaço dentro de uma figura 3D. Medido em m³, cm³, litros, etc.

Cubo ou Bloco: Volume = comprimento × largura × altura = C × L × A

Se C = 4m, L = 3m, A = 2m:
Volume = 4 × 3 × 2 = 24m³
Cilindro: Volume = π × raio² × altura = πr²h

Se raio = 2m, altura = 5m (π ≈ 3,14):
Volume = 3,14 × 2² × 5 = 62,8m³
