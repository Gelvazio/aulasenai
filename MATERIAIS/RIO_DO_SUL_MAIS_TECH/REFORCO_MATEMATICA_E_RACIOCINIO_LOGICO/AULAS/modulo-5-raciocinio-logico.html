🎯 Introdução — O Poder do Raciocínio

Raciocínio lógico é a habilidade de pensar de forma estruturada e resolver problemas novos usando princípios estabelecidos. Programadores, engenheiros, detectives e cientistas usam raciocínio lógico todos os dias!

🧩 Quebra-Cabeças e Lógica

Desafios lógicos desenvolvem pensamento estruturado

💻 Programação

Programadores precisam pensar logicamente para escrever código

📚 1. Reconhecendo Padrões

Um padrão é uma sequência que se repete ou segue uma regra. Identificar padrões é uma habilidade central em raciocínio lógico.

Padrões Numéricos

Sequência Aritmética: 2, 5, 8, 11, 14...
Padrão: adiciona 3 a cada número
Próximo: 17
Sequência Geométrica: 1, 2, 4, 8, 16...
Padrão: multiplica por 2 a cada número
Próximo: 32
Fibonacci: 1, 1, 2, 3, 5, 8, 13...
Padrão: cada número é a soma dos dois anteriores
Próximo: 21

📚 2. Lógica Proposicional

Proposição é uma afirmação que é VERDADEIRA ou FALSA.

Proposição Simples: "2 + 2 = 4" (Verdadeira)
Proposição Simples: "Paris é capital da Alemanha" (Falsa)

Conectivos Lógicos

  • E (AND): Ambas as proposições devem ser verdadeiras
  • OU (OR): Pelo menos uma das proposições deve ser verdadeira
  • NÃO (NOT): Inverte o valor lógico
Exemplo E: "É dia E está chovendo"
Só é verdade se AMBAS são verdadeiras
Exemplo OU: "Você ganha em futebol OU em videogame"
É verdade se ganhar em pelo menos UM dos dois

📚 3. Estratégias de Resolução

1. Tentativa Sistematizada

Testar possibilidades de forma ordenada até encontrar a solução

Problema: Qual número, multiplicado por 5, mais 3, resulta em 28?
Teste: 1×5+3=8 (não), 2×5+3=13 (não), 3×5+3=18 (não), 4×5+3=23 (não), 5×5+3=28 (SIM!)

2. Decomposição

Quebrar o problema em partes menores

Problema Grande: Organizar uma viagem
Partes: Escolher destino → Comprar passagem → Reservar hotel → Arrumar mala

3. Trabalho Reverso

Começar do resultado e trabalhar para trás

Problema: Um número depois de somar 10 é 25. Qual era?
Reverso: 25 − 10 = 15

4. Analogia

Usar problemas semelhores que você já resolveu

"Se consigo resolver para 2 elementos, posso resolver para 10"

📚 4. Puzzles e Desafios Lógicos

Sudoku, jogo da velha, xadrez e outros jogos desenvolvem lógica.

Desafio Classic: Três pessoas precisam atravessar um rio. O barco cabe 2 pessoas. Como todos atravessam?
Solução: Pessoa A + B vão, A volta, A + C vão, B volta, A + B vão de novo.
💡 Dica: Quando preso em um problema lógico, pause, respire, e tente uma estratégia diferente.
