**Regra geral de correção de cada tópico:** nota cheia = atende a todos os critérios com as palavras do aluno; metade = atende parcialmente; zero = em branco, errado, fora do tema ou copiado.

### ITEM 01-a
**Resposta esperada:** UI é a camada visual com que a pessoa interage na tela: botões, cores, fontes, sombras e espaçamentos.
**Critérios:** Nota cheia: define UI pelo que a pessoa vê e toca na tela, com as palavras do aluno (botões, cores ou fontes). Metade: cita elementos visuais, mas sem ligar à interação na tela. Zero: define UI como o sistema por trás, a jornada ou em branco.

### ITEM 01-b
**Resposta esperada:** UX é a jornada completa da pessoa com o sistema, incluindo a sensação de controle, a rapidez para resolver o problema e a ausência de obstáculos estressantes.
**Critérios:** Nota cheia: descreve UX como jornada ou experiência total e cita pelo menos um aspecto (controle, rapidez ou ausência de obstáculos). Metade: define UX só como "a experiência" ou só como "usabilidade", sem a jornada. Zero: define UX como visual ou em branco.

### ITEM 01-c
**Resposta esperada:** O problema está na UX, pois a aparência é boa, mas os usuários não conseguem concluir a marcação. Fato do enunciado: a marcação não é concluída mesmo com botões bem desenhados.
**Critérios:** Nota cheia: aponta UX como o aspecto que falhou e justifica com o fato de a marcação não ser concluída apesar do visual bom. Metade: aponta UX sem justificar com o enunciado, ou cita o visual como falha parcial. Zero: aponta UI como falha ou em branco.
