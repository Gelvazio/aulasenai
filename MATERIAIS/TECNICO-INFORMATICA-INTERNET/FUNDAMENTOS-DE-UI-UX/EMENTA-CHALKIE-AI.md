## 📚 I. CONTEXTO E ALINHAMENTO

### Justificativa
Toda página web é usada por pessoas. Antes de codificar o front-end, quem desenvolve precisa entender quem usa a tela, o que essa pessoa quer fazer e como formas, cores, layout e navegação ajudam ou atrapalham. A UC dá a base de interface (UI) e de experiência do usuário (UX): princípios de design, pesquisa com o usuário, prototipagem e direito autoral. Prepara para Codificação para Front-End e Projeto de Front-End.

### Função (módulo Introdutório) [oficial]
● 1 - Produzir Interfaces para internet, de acordo com metodologia e padrões de qualidade, usabilidade, interatividade, robustez, acessibilidade e segurança da informação. ● 2 - Desenvolver sistemas para internet, de acordo com metodologia e padrões de qualidade, usabilidade, interatividade, robustez, acessibilidade e segurança da informação.

### Objetivo geral [oficial]
Desenvolver as capacidades básicas e as socioemocionais requeridas para compreender os princípios de design, considerando a experiência do usuário no desenvolvimento de interfaces

- **SA 1 — Diagnóstico visual de uma página (aulas 1–9).** Você, como aluno consultor, foi chamado para analisar a página de agendamento de um serviço on-line que recebe muitas reclamações de quem a usa pelo celular. **Práticas das aulas (didático):** 20 questões × 3 tópicos (0,2 + 0,4 + 0,4), nota proporcional até 10. **Avaliação prática:** 20 × 3 (0,1 + 0,2 + 0,2) = 10 pontos.

**Recuperação (didático):** refazer a avaliação não atingida com outra situação ou novo banco de questões, conforme o regimento da unidade SENAI.

## 📘 XI. GLOSSÁRIO

**Design** — planejamento da forma e da função de um produto para atender a um objetivo · **Hierarquia visual** — ordem de importância que o olhar percebe entre os elementos · **Contraste** — diferença de cor, tamanho ou forma que destaca um elemento · **Cenário** — descrição de uma situação de uso: quem, onde, com que objetivo.
