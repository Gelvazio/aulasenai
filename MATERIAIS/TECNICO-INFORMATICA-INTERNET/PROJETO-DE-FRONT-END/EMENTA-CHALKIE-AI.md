## Ementa da UC (copiada da ementa do curso)

| Campo | Valor |
|---|---|
| **Módulo** | ESPECÍFICO I |
| **Carga horária** | 90h |
| **Função** | ● 1 - Produzir Interfaces para internet, de acordo com metodologia e padrões de qualidade, usabilidade, interatividade, robustez, acessibilidade e segurança da informação. |

**Objetivo geral:** Propiciar o desenvolvimento de capacidades técnicas e socioemocionais para o desenvolvimento de projetos de Front-End

### Subfunções

- 1.1 Testar interfaces para garantia da qualidade da entrega 1.2 Codificar interfaces para arquitetura client-side 1.3 Projetar interfaces para atender o escopo do projeto

### Padrões de desempenho

- 1.1.1 Considerando plano de execução de teste
- 1.1.2 Considerando as especificações técnicas para a documentação dos testes
- 1.1.3 Considerando os métodos, normas e procedimentos de teste para correção e implementação
- 1.2.1 Utilizando linguagem de marcação e folhas de estilo de acordo com recomendações técnicas
- 1.2.2 Utilizando linguagens de programação para arquitetura do lado do cliente
- 1.2.3 Considerando os frameworks de programação e estruturação do lado do cliente de acordo com boas práticas
- 1.3.1 Elaborando protótipos de interface para internet
- 1.3.2 Considerando padrões de design de interação para garantia da experiência do usuário (ux e ui)
- 1.3.3 Considerando técnicas de levantamento dos requisitos da aplicação
- 1.3.4 Levantando as necessidades do cliente
- 1.3.5 Considerando procedimentos de modelagem

- Aplicar técnicas de versionamento de software
- Seguir recomendações técnicas na aplicação da linguagem de programação
- Aplicar técnicas de versionamento de software

- Aplicar técnicas de versionamento de software
- Definir tipo de protótipo de interface para web

- Aplicar padrões de ux no projeto da interface para web
