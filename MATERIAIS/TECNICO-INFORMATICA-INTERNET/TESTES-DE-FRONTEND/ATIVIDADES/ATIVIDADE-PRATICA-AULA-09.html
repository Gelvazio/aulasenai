Como Responder

📋 INFORMAÇÕES GERAIS
Duração: 90–120 minutos
Formato: Discursiva estruturada (o aluno digita a resposta de cada tópico no sistema)
Total de questões: 10 (30 tópicos)
Pontuação: 1,0 ponto por questão, dividido em 3 tópicos (0,2 + 0,4 + 0,4) — total: 10 pontos
CAPACIDADES

C5 — Desenvolver conjunto de testes automatizados

💡 SEU PAPEL EM TODAS AS QUESTÕES
Você, como aluno consultor, foi chamado porque uma loja virtual publicou duas vezes no mesmo mês uma versão com o carrinho quebrado ("os testes existiam, mas ninguém rodou"). Você vai montar o pipeline de testes no GitHub, proteger a branch main e auditar a acessibilidade e o desempenho do checkout.
💡 COMO RESPONDER
Cada questão tem 3 tópicos, e cada tópico tem o seu campo. Responda somente o que o tópico pede: (1) o conceito ou o comando pedido; (2) o código pedido escrito por inteiro (trecho do workflow em YAML, teste com expect, HTML corrigido) ou os valores pedidos; (3) uma frase curta de justificativa quando o tópico pedir "explique" ou "justifique". No YAML, use 2 espaços por nível. Respostas copiadas da internet ou de colegas recebem nota zero no tópico.
💡 COMO A CORREÇÃO FUNCIONA
cada tópico é comparado com o padrão de resposta do professor: conceito certo, código correto (chaves do workflow, ordem dos passos, teste com o matcher adequado, atributo de acessibilidade) e justificativa com as palavras-chave do conteúdo. Nomes de jobs e de arquivos diferentes valem, desde que o código esteja correto; aspas simples ou duplas são aceitas. Erros de português não tiram nota se a ideia estiver clara.
💡 PROJETO USADO EM VÁRIAS QUESTÕES
a loja usa Vitest (script test:coverage, com metas mínimas de cobertura) e Cypress, roda em http://localhost:5173 com npm run dev e guarda o código no GitHub, na branch main. O checkout é montado por montarCheckout(container), do arquivo src/checkout.js.
