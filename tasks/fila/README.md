# 🗂️ Fila de tasks no GitHub

Cada task criada na página `tasks.html` (tabela `tasks` do Supabase) tem aqui o arquivo
`TASK-NNNN.md`, gerado por `python3 scripts/tasks/sincronizar_tasks.py exportar <linhas.json>`
(não editar à mão). As tarefas do `tasks/TASKS.md` também estão na tabela (entram desligadas).

Regra: "toda task existe na tabela e no GitHub" — [docs/regras/tarefas-agendadas.md](../../docs/regras/tarefas-agendadas.md).
